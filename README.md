![CI](https://img.shields.io/github/actions/workflow/status/nsis-community/plugin-baseconvert/ci.yml?style=for-the-badge)

This repository mirrors the BaseConvert plug-in, which was previously hosted on the [NSIS wiki](https://nsis.sourceforge.io/). Its source has been rearranged so that it builds automatically; code changes are limited to build fixes.

**Are you the author?** You're welcome to take it over: [open an issue](https://github.com/nsis-community/plugin-baseconvert/issues/new) and we'll transfer the repository to you.

## Installation

Download the installer or archive from the [Releases page](https://github.com/nsis-community/plugin-baseconvert/releases).

If you downloaded the zip archive, extract it into your NSIS folder: it adds `BaseConvert.dll` to `Plugins/<variant>/`.
